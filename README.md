Vector Duel is a local 1v1 2D space combat game which lets users experience real life rocket physics built with a custom 60fps physics engine. 

> Rockets maintain vector velocity unless counter-thrust is applied.
> Rockets launch tracking projectiles that follow the enemy, every impact transfers momentum.
> Charging the core to 100% unleashes a magnetic field which bends trajectory paths dynamically. (not really physics, but why not)


🛠️ Tech Stack

Framework: React
Styling: Tailwind CSS 
Build Tool: Vite
Rendering: HTML5 2D Canvas API
Physics Engine: Custom Vanilla JavaScript Engine (`GameEngine.js`)
